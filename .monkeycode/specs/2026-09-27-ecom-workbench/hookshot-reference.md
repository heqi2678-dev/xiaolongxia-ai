# HookShot（霍客引擎）参照说明

用于「图片工坊」（设计稿 2.4 `ecom-image` / 12.1 一期）的界面与成品对齐。

来源：https://www.hkshot.com/ （用户于 2026-09-28 指定）。站点为 Vite + React 单页应用，
内容由 JS 渲染，以下信息取自站点首页元数据与其构建产物 `assets/index-DSDU11JY.js`。

## 1. 产品定位

一站式 AI 电商设计：AI 生成亚马逊/淘宝主图、商品图、详情页与视频，覆盖 30+ 主流电商平台，
含 AI 助手。面向跨境与国内铺货场景（与设计稿 4.1/4.2 的平台清单一致）。

## 3. 商品图设计工具清单（`商品图设计-*`）

主图、产品替换、使用场景图、卖点图、商品套图、商品详情页、图片复刻、场景替换、
场景渲染图、尺寸图、白底图、细节图、营销海报。

其它能力关键词：AI 白底图、AI 抠图（含局部重绘、加字幕）、AI 模特（真人模特/换头/换背景/
换装/换色）、图片精修、画质修复、扩图、擦除、翻译、图片尺寸修改、图片复刻、批量任务/批量下载。

## 4. 典型操作流（图片工坊应对齐）

1. 上传原图（单个物品的白底图/透明底图效果最佳）。
2. 选择配方或模板（如「套图配方」；详情页可选长图模板做「复刻」）。
3. 选择平台与分辨率/宽高比（站点内置「分辨率对照表」，可点编辑参数改各图类型的
   分辨率与宽高比）。
4. 选定模型；详情页/套图等支持「全局批量设置（应用于下方所有任务）」。
5. 批量提交（套图配方可对全部上传图批量生成），任务异步执行。
6. 结果预览 → 批量下载；任务记录在 `/task-record-dashboard`，素材沉淀在 `/my-assets`。

## 5. 我方落点口径（按设计稿分工）

- **图片工坊（一期，`ecom-image`）**：主图制作 + 详情页。主图覆盖白底图、卖点图、细节图、
  尺寸图、使用场景图、场景渲染图、营销海报、商品套图；详情页覆盖详情长图生成与图片复刻。
  复用短剧侧生成适配器、画布、资产库、参考图机制（设计稿 3.2）。
- **AI 创作（二期，`ecom-ai`）**：短视频带货制作，参照 HookShot `/video-agent`
  与「视频复刻」；不在图片工坊内实现。
- 成品形态对齐：上传 → 配方/模板 → 平台规格（分辨率/宽高比）→ 批量任务 → 预览/下载，
  并落 `my-assets`、任务记录。
