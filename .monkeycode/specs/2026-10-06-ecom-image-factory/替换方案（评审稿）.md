### 5.1 工作台
- 4 大功能卡：AI 作图 / AI 生成视频 / AI 详情页 / 跨境本地化。
- 4 个数据块：本月生成、导出素材、在用积分、累计项目。
- 最近项目卡（主图组 / 短视频 / 本地化，带状态徽标）。
- **复用**：现有 `ecom-home.js` 的卡片+统计+列表结构可作模板，换数据源。
- **新建**：summary 接口与"本月/积分/项目"数据模型。

### 5.2 AI 作图（最大缺口）
- 12 工具卡：Agent 模式、主图套图、精修白底图、AI 试衣、万物穿戴、商品替换、图片翻译、去除水印、姿势裂变、商品换色、商品精修、海报设计。
- 大白话输入框 + 上传槽（0/10）+ 底部 pill（Agent 模式 / 智能比例·1K / 技能库）+ 积分消耗与发送。
- HOT 灵感推荐（6 条示例，点击填 prompt）。
- **复用**：现有图片工坊的 `white/promo/detail/size/scene/poster/suite` 配方可覆盖「主图套图 / 精修白底图 / 海报设计」约 3 项。
- **新建（约 8-9 项）**：Agent 对话式生成、AI 试衣、万物穿戴、商品替换、图片翻译、去水印、姿势裂变、商品换色、商品精修。均属图像生成能力，需接生成适配器。

### 5.3 AI 详情图
- 上传主商品图（0/6）+ 补充素材（SKU 图 / 细节图）+ 要求文本框（带 AI 帮写）+ 风格 chips + 目标平台 / 语言 / 清晰度 / 尺寸比例 + 「生成设计规划方案」。
- 右侧空态说明（卖点解析 / 多场景生成 / 整套排版）。
- **复用**：图片工坊的 `detail_long` / `recreate` 作底层。
- **新建**：卖点解析、整套详情图规划与排版、多场景生成链路。

### 5.4 主图编辑（列表 / 画布双模式）
- 工具栏：选择 / 文字 / 抠图 / AI 换背景 / 列表↔画布切换 / 导出主图。
- 左「元素库」：背景、商品主体、主标题、价格标签、促销角标。
- 列表模式：逐元素行（拖拽排序、编辑、删除、+ 添加元素）。
- 画布模式：元素绝对定位拖拽，选中态；右「属性」面板（类型 / 文本 / X·Y 位置 / 颜色 / 图层）。
- **复用参考**：短剧侧 `canvas.js` / `manual.js` 的画布交互思路，但对象模型不同。
- **新建**：电商主图文档模型、元素原子、导出（PNG/尺寸规格）。

### 5.5 详情页编辑（列表 / 画布双模式）
- 模块库：主图区、卖点区、参数表、使用场景、对比图、买家口碑。
- 列表模式：纵向模块堆叠（拖拽排序、逐块编辑）。
- 画布模式：artboard 内块级布局（商品主图 / 标题区 / 三列信息 / 参数行）。
- **新建**：详情页文档模型、模块原子、导出长图。

### 5.6 跨境本地化
- 目标市场（马来西亚 / 美国 / 欧洲 / 东南亚）、文案语言（English / Bahasa Melayu / 中文 / 日本語）、模特族裔（亚裔 / 欧美 / 非裔 / 拉美）、目标平台、视频本地化配音开关、「生成本地化素材」。
- 右侧手机预览（TikTok 样式）。
- **新建**：翻译、换模特、平台规格适配、视频字幕+配音（配音复用短剧 TTS 适配器）。

### 5.7 作品库
- 顶部筛选（全部 / 图片 / 视频 / 详情页）+ 搜索 + 排序；瀑布流网格；每个作品悬浮操作（下载 / 编辑 / 删除）；视频时长徽标；分页。
- **复用/改造**：现有 `ecomAssets`（素材网格）+ `ecomProducts` 的数据层思路。
- **新建**：统一作品模型（图片 / 视频 / 详情页 / 本地化），跨类型筛选与批量操作。

## 六、技术要点

### 6.1 生成能力复用（关键）
短剧分区已有 BYOK 模型目录与统一适配器：`src/drama/config.js`、`adapters.js`、`adapters/{image,video,tts,lipsync}.js`。工厂的「AI 作图 / AI 详情图 / 本地化」直接复用该层，只需新增业务调用，无需重造生成底座。后端若需代签/转发，沿用短剧侧网关做法。

### 6.2 资产与本地库
图片/视频产物沿用短剧侧资产链路：`src/drama/project.js` 的 IndexedDB 本地资产库、`toRef/hydrateRef/cacheRemote`、以及 `gate/server.py` 的 `/api/drama/asset` 上传换公网地址。作品库与短剧资产**共用 IndexedDB 时须命名空间隔离**（旧 ecom 的遗留约束，仍适用）。

### 6.3 数据模型（建议新表）
`works`（作品主记录：类型/标题/来源/状态/归属 owner）、`work_versions`（版本）、`work_assets`（作品↔素材）、`editor_docs`（主图/详情页编辑文档，JSON）、`gen_tasks`（生成任务）。

### 6.4 与登录 / 部署的关系
- 电商接口继续复用 owner 会话（登录体系不变）。
- 后端改动后需 `systemctl restart xiaolongxia-gate.service`；前端静态文件覆盖即生效。
