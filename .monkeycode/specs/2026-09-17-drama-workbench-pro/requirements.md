# 需求文档 · AI 短剧工作台专业范式重构

## 引言

本需求把现有「表单式」AI 短剧工作台升级为专业创作范式，对标 LibTV 一类专业视频创作工具。改造保留「手搓台」与「半自动台」两个台，两者共用同一套项目模型、生成引擎与合成链路，界面统一为「项目中心 + 创作台」的缩略图驱动范式。改造同时接通真实云端模型（火山方舟 Seedream / Seedance、火山语音合成、火山口型驱动），使界面操作真正产出成片。

现状要点（作为改造基线）：
- 视图入口：`index.html` 中两个视图容器 `#dramaView`（手搓台）与 `#autoView`（半自动台），脚本按序加载 `src/drama/*.js`。
- 数据模型：`src/drama/project.js` 定义工程 `{ id, title, genre, engine, script, characters, shots, style, subtitle, bgm, output, compliance, source }`，草稿存 localStorage，大块资源存 IndexedDB。
- 共用部件：`src/drama/ui.js` 提供分镜卡、角色卡、合规区、角色库面板与 `ensureCss()`。
- 生成链路：`src/drama/engine.js` + `src/drama/adapters/*.js`（image / video / tts / lipsync）。
- 合成链路：`src/drama/compose.js`（浏览器合成）与 `gate/server.py` 的 `drama_compose`（服务端 ffmpeg）。
- 配置：`src/drama/config.js` 的 provider 目录与 `getSettings/setAdapterConfig/isConfigured`。

## 术语表

- **工作台**：AI 短剧工作台的统称，包含项目中心与两个创作台。
- **项目中心**：工作台首页，以缩略图卡片网格呈现全部工程，支持新建、打开、删除、搜索与排序。
- **导演台**：手搓台重构后的创作界面，手搓台对应用户故事中的「逐镜精修」。
- **流水线**：半自动台重构后的创作界面，以「一句话点子」为起点依次推进到成片。
- **分镜**：工程内的一个镜头单元，含提示词、台词、运镜、时长、角色、素材与状态。
- **缩略图**：分镜或工程的可视化预览图，取画面图、视频首帧或占位图。
- **模型档位**：一类可选的云端模型配置，包含 provider、具体 model id、Key 与端点。
- **未配置回退**：模型档位缺少可用凭证时，工作台使用内置模板或占位内容继续流程。
- **状态**：分镜的生成状态，取值 `pending`（待生成）、`generating`（生成中）、`done`（已完成）、`failed`（失败）。

## 需求

### 需求 1 · 项目中心

**用户故事：** 作为短剧创作者，我希望在一个项目中心看到所有剧集的可视化卡片，以便快速新建、打开与整理作品。

#### 验收标准

1. 当用户进入工作台首页时，工作台应展示项目中心，并以缩略图卡片网格呈现全部工程。
2. 项目中心应在每张卡片上展示工程缩略图、标题、剧种、分镜数量与最近更新时间。
3. 当项目数量为零时，项目中心应展示新建引导与示例题材入口。
4. 当用户点击某张卡片时，工作台应打开对应工程并进入其创作台（依 `source` 进入导演台或流水线）。
5. 当用户在项目中心搜索框输入关键词时，工作台应仅展示标题或题材命中关键词的工程。
6. 当用户删除工程时，工作台应在二次确认后移除该工程及其本地资源引用。
7. 项目中心应内置题材模板，每个模板包含剧种、画风、分镜结构与示例提示词。
8. 当用户选择题材模板新建工程时，工作台应基于模板生成初始工程并进入对应创作台。

### 需求 2 · 导演台布局

**用户故事：** 作为短剧创作者，我希望手搓台提供「分镜列表 + 大预览 + 属性面板 + 时间轴」的导演台布局，以便像专业工具一样逐镜精修。

#### 验收标准

1. 当用户进入导演台时，工作台应在左区展示分镜缩略图列表、中区展示竖屏画布预览、右区展示当前选中分镜的属性，底部展示时间轴。
2. 当用户点击左区某个分镜时，工作台应在中区加载该分镜的预览，并在右区展示该分镜的属性。
3. 当预览区宽度或高度受限时，工作台应保持画幅比例并按 `output.ratio` 计算预览尺寸。
4. 当窗口宽度小于 900 像素时，工作台应将左区与右区收纳为可切换抽屉，中区预览保持可见。
5. 当用户切换当前分镜时，工作台应与既有键盘焦点顺序保持一致，属性面板中的首字段获得焦点。

### 需求 3 · 分镜缩略图与状态可视化

**用户故事：** 作为短剧创作者，我希望每个分镜以缩略图卡片呈现并标注状态，以便一眼看出哪些镜头需要处理。

#### 验收标准

1. 工作台应在分镜缩略图上叠加状态标记，取值与「状态」术语一致。
2. 当分镜已有画面素材时，工作台应展示画面缩略图；否则展示占位图与镜号。
3. 当分镜处于 `generating` 状态时，工作台应在该缩略图上展示进度指示。
4. 当分镜生成失败时，工作台应在缩略图上展示失败标记，并在属性面板展示错误原因。
5. 工作台应在时间轴上以等宽色块呈现各分镜，色块长度按分镜时长比例计算。

### 需求 4 · 逐镜生成与片段重拍

**用户故事：** 作为短剧创作者，我希望对单个分镜重新生成而不影响其他分镜，以便在少量镜头不满意时精准返工。

#### 验收标准

1. 当用户点击某分镜的生成操作时，工作台应仅对该分镜发起点下操作，并保持其他分镜的素材与状态不变。
2. 当用户点击某分镜的重拍操作时，工作台应为该分镜保留原有属性，仅替换生成的素材。
3. 当生成处于进行中时，工作台应对同一分镜的重复点击进行抑制，并在完成后恢复交互。
4. 当生成失败时，工作台应保留该分镜的既有素材并展示可重试入口。
5. 当用户对已时长修改的分镜执行重拍时，工作台应使用修改后的时长参数。

### 需求 5 · 逐帧拉片预览

**用户故事：** 作为短剧创作者，我希望在预览区逐帧查看成片素材，以便在合成前确认节奏与画面。

#### 验收标准

1. 当分镜存在视频或口型素材时，工作台应在预览区提供播放、暂停、逐帧前进与逐帧后退操作。
2. 当用户点击逐帧前进或逐帧后退时，工作台应将播放位置移动一帧。
3. 工作台应在预览区展示当前时间与素材总时长。
4. 当素材不可播放时，工作台应展示画面缩略图并提示素材状态。

### 需求 6 · 时间轴与配音字幕轨

**用户故事：** 作为短剧创作者，我希望在底部时间轴看到画面、配音与字幕三条轨，以便统一检查音画同步。

#### 验收标准

1. 工作台应在时间轴展示画面轨、配音轨与字幕轨。
2. 当分镜存在配音素材时，工作台应在配音轨对应区间展示波形或时长条。
3. 当分镜存在台词且已开启字幕时，工作台应在字幕轨对应区间展示字幕条。
4. 当用户在时间轴点击某一位置时，工作台应将当前分镜切换到该位置所属分镜。

### 需求 7 · 流水线

**用户故事：** 作为短剧创作者，我希望半自动台以「一句话点子 → 分镜网格 → 批量生成 → 成片」推进，且每一步都可视化，以便低门槛快速产出。

#### 验收标准

1. 当用户进入流水线时，工作台应展示阶段条，阶段依次为输入题材、审剧本、角色锁定、批量生成、逐镜检查、配音字幕、合成成片、终审发布。
2. 当用户在输入题材阶段提交一句话点子时，工作台应调用剧本规划生成分镜草案，并以缩略图网格展示草案。
3. 当分镜草案生成完成时，工作台应允许用户在网格内直接修改提示词与台词。
4. 当用户通过审剧本阶段时，工作台才应进入批量生成阶段并发起真实生成。
5. 当批量生成进行中时，工作台应在分镜网格上逐个展示完成进度。
6. 当批量生成完成时，工作台应进入逐镜检查阶段，允许对单个分镜重拍后再继续。

### 需求 8 · 模型选择器与配置引导

**用户故事：** 作为短剧创作者，我希望在创作台内直接选择图像、视频、语音与口型模型，以便按成本与效果切换。

#### 验收标准

1. 工作台应在创作台提供图像、视频、语音、口型四类模型档位的选择入口。
2. 当用户选择某类模型档位时，工作台应展示该档位可用的具体 model id 列表。
3. 当某类模型档位缺少可用凭证时，工作台应在选择处展示「未配置」标记，并提供跳转设置页的入口。
4. 当用户更改模型档位时，工作台应将该选择持久化到本地设置，并在后续生成中生效。
5. 当模型档位未配置且用户继续创作时，工作台应使用「未配置回退」完成流程并在结果上标注回退来源。

### 需求 9 · 真实模型接入与任务轮询

**用户故事：** 作为短剧创作者，我希望工作台真实调用云端模型并在界面展示进度，以便产出可发布的成片。

#### 验收标准

1. 当用户发起视频生成时，工作台应调用所选视频 provider 的任务式接口并轮询任务状态，直到任务成功或失败。
2. 当用户发起图像生成时，工作台应调用所选图像 provider 的生成接口并取得图片地址或二进制数据。
3. 当用户发起配音时，工作台应调用所选语音 provider 并取得音频地址或二进制数据。
4. 当任务处于进行中时，工作台应在对应分镜上展示真实进度。
5. 当接口返回错误时，工作台应展示错误码与可读说明，并保留该分镜的既有素材。

### 需求 10 · 资产库

**用户故事：** 作为短剧创作者，我希望集中浏览角色与生成素材，以便跨分镜与跨工程复用。

#### 验收标准

1. 工作台应提供资产库入口，展示角色、参考图与已生成素材。
2. 当用户从资产库选取角色时，工作台应将该角色加入当前工程。
3. 当用户从资产库选取素材时，工作台应将该素材设为所选分镜的画面或配音来源。
4. 工作台应支持跨工程复用角色库记录。

### 需求 11 · 合规与授权

**用户故事：** 作为短剧创作者，我希望合规要求内建在创作流程中，以便发布时不触碰平台红线。

#### 验收标准

1. 工作台应在合成与导出前校验 AI 生成标注与肖像授权。
2. 当工程涉及真人形象且缺少肖像授权时，工作台应阻止合成与导出并展示待办项。
3. 当工程为漫剧剧种时，工作台应免于肖像授权校验。
4. 工作台应在成片上保留 AI 生成标注。

### 需求 12 · 响应式与可访问

**用户故事：** 作为短剧创作者，我希望在手机与桌面都能顺畅操作，以便随时处理镜头。

#### 验收标准

1. 当视口宽度小于 900 像素时，工作台应以单列布局呈现，且全部主操作无需横向滚动即可触达。
2. 当视口宽度大于等于 900 像素时，工作台应以多区布局呈现。
3. 工作台内的可点击元素应具备不小于 32 像素的命中区域。
4. 工作台应保证视图内的纵向内容可滚动到底部，且不被固定底栏遮挡。

### 需求 13 · 数据兼容与迁移

**用户故事：** 作为既有用户，我希望升级后仍能打开原有工程，以便不丢失已有草稿。

#### 验收标准

1. 当工作台加载既有 localStorage 工程时，工作台应按既有字段读取并补齐缺失字段。
2. 当既有工程缺少新增字段时，工作台应使用默认值填充而不阻断打开。
3. 当既有工程含 IndexedDB `asset:` 引用时，工作台应在展示时解析为可显示地址。

## 已确认决策

| 决策项 | 结论 |
|---|---|
| 目标形态 | 保留手搓台与半自动台两个台，两者都升级为专业创作范式 |
| 逐帧拉片与时间轴 | v1 即实现完整版：播放 / 暂停 / 逐帧前进 / 逐帧后退 / 当前时间与总时长，以及画面 + 配音 + 字幕三轨时间轴 |
| 项目中心 | 内置题材模板，新建时可直接套用 |
| 模型接入顺序 | 以火山方舟全家桶为主（Seedream 图像、Seedance 视频、火山语音合成、火山口型驱动），其余厂商保留自定义接入能力 |

## 依赖与约束

- 云端模型依赖用户自备 API Key，Key 只存本地，不写入仓库、不上传服务端。
- 服务端合成依赖 `gate/server.py` 的 `drama_compose` 与系统 `ffmpeg`、中文字体。
- 浏览器合成依赖 Canvas 与 MediaRecorder。
- 现有测试基线须保持通过：`node --test tests/drama.test.js`、`NODE_PATH=/usr/local/lib/node_modules node tests/drama-e2e.js`、`cd gate && python3 -m unittest test_gate`、`python3 tests/layout_audit.py`。
