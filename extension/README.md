# 小龙虾 · 1688 采集扩展

在已登录的 1688 页面上读取渲染后的商品数据，一键采集到小龙虾电商工作台。不申请 1688 开放平台凭证，插件只读页面、不代填账号密码。

## 安装

1. 下载并解压 `ecom-collect-extension.zip`（或直接使用本目录）。
2. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的目录（含 `manifest.json` 的那一层）。
4. 点扩展图标，填写：
   - **站点地址**：小龙虾后端地址，默认 `http://47.108.14.206/dian/api/ecom`
   - **插件口令**：在小龙虾「电商工作台 → 采集下载 → 插件采集」点「生成口令」后复制
   - **批量间隔**：默认 800 毫秒
5. 点「保存」，再点「测试连接」确认口令有效。

## 使用

- 打开 1688 **商品详情页**：点右下角「采集本商品」。
- 打开 1688 **搜索/列表页**：点「采集本页商品」，逐个详情页采集当前页全部商品。
- 采集成功后商品进入「商品库」，图片由后端带来源头转存到本机并生成对外地址。

## 说明与限制

- 采集范围为本页商品，不自动翻页整店全量。
- 只对 `*.1688.com` 生效；非 1688 页面不显示入口。
- 站点地址为 HTTP 时，扩展跨站请求可能受浏览器混合内容策略限制；如遇失败，请给站点配置可信任 HTTPS，或改用 HTTPS 地址。
- 口令仅存 `sha256` 于服务端，明文只在生成时展示一次；泄露可在「插件采集」面板撤销重发。
