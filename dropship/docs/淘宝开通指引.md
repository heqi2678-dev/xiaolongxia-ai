# 淘宝开通与铺货指引（自用型应用）

本阶段只做淘宝，TikTok 暂缓。目标：用你自己的店铺账号，把「1688 采集的商品」通过淘宝官方 API 发布上架。

整条链路：
```
1688 商品页（浏览器扩展采集） → 货源库 → 类目/字段映射 → 发布队列 → 淘宝开放平台 API → 店铺上架
```

需要你在淘宝开放平台操作的部分（下面 1~4 步），平台侧凭据拿到后填进系统即可。

---

## 1. 注册开发者并完成认证

1. 打开 https://open.taobao.com ，用**企业支付宝/淘宝账号**登录
2. 进入「控制台 → 账号管理」，提交**开发者认证**
   - 商品发布类接口要求**企业**认证（营业执照 + 对公账户）
   - 认证通过后才能申请发布权限
3. 认证一般 1~3 个工作日；期间可以先看接口文档

## 2. 创建自用型应用

1. 「控制台 → 应用管理 → 创建应用」
2. 应用类型选 **自用型应用**（只服务自己店铺，无需上架审核，通常免费）
3. 创建后进入应用详情，记录：
   - **AppKey**（应用唯一标识）
   - **AppSecret**（应用密钥，用于签名，只显示一次，务必保存）

## 3. 申请接口权限

在应用详情「权限管理」里申请以下权限包（自用型应用按需勾选）：

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 类目查询 | `taobao.itemcats.get` | 取叶子类目 cid |
| 属性查询 | `taobao.itemprops.get` | 取类目必填属性 |
| 图片上传 | `taobao.picture.upload` | 主图上传到图片空间 |
| 商品发布 | `taobao.item.add` | 新建商品 |

## 4. 配置回调地址并完成授权

1. 在应用详情设置 **OAuth 回调地址**（也叫授权回调地址）
   - 抄下这个地址，原样填进系统的 `DROPSHIP_OAUTH_REDIRECT`
2. 打开系统的「铺货」板块，平台列表里点淘宝 **去授权**：
   - 系统会用你的 AppKey 拼出授权链接并打开
   - 用**卖家账号**登录并同意授权
   - 授权后浏览器会跳转到回调地址，**把跳转地址里的 `code=...` 参数（或整段地址）复制**，粘贴回系统弹窗
   - 系统用它换取 `access_token` 并保存（会自动刷新，无需手工续期）

> 说明：因为铺货后端默认只监听本机回环，回调页未必能被外部浏览器直接访问；直接复制 `code` 回填即可完成，不依赖回调页可达。

## 5. 把凭据填进系统（服务器操作）

编辑 `/etc/xlx-dropship.env`：

```bash
DROPSHIP_TAOBAO_APP_KEY=你的AppKey
DROPSHIP_TAOBAO_APP_SECRET=你的AppSecret
DROPSHIP_OAUTH_REDIRECT=你在淘宝后台登记的回调地址
# 建议先设一个访问令牌，防止接口裸奔
DROPSHIP_EXT_TOKEN=自己定一串随机字符串
# 联调阶段先保持试运行
DROPSHIP_DRY_RUN=1
```

改完重启服务：

```bash
sudo systemctl restart dropship.service
curl -fsS http://127.0.0.1:9150/health && echo
```

## 6. 准备一件可发布的商品

在「铺货」板块，从 1688 采集一条货源后，逐项补齐（缺任一会被上架前校验拦下）：

- **类目映射**：给商品填平台类目 ID（`category.target.id`）
- **标题**：30 字内，避开违规词/品牌词
- **主图**：至少一张；稳妥做法先点「归档图」，把 1688 防盗链图片下载到本地再上传
- **SKU**：价格与库存
- **属性**：类目必填属性（如材质、尺码）

## 7. 先试运行，再真实发布

1. `DRY_RUN=1` 时点「铺货」，任务会走完整流程但不真正调用淘宝 API（`status=dry_run`），用来验证字段映射
2. 确认无误后把 `DROPSHIP_DRY_RUN=0` 重启，再发一次；建议**先发 1 件到店铺**观察
3. 任务失败可在列表点「重试」；错误信息会写进任务 `lastError`

---

## 常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 授权时报「缺少 AppKey」 | `DROPSHIP_TAOBAO_APP_KEY/SECRET` 未填或未重启服务 |
| 签名失败 / `Invalid signature` | 系统北京时间偏差需在 10 分钟内；校时后重试 |
| `isv.invalid-parameter` 非法参数 | 类目/属性与类目模板不匹配，换正确叶子类目并补必填属性 |
| 图片 403 / 裂图 | 1688 图有防盗链；先「归档图」转本地图床再发布 |
| 权限不足 / no permission | 第 3 步权限包未申请或未通过审核 |
| 发布返回 dry_run | `DROPSHIP_DRY_RUN` 仍为 1 |
