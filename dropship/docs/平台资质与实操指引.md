# 铺货系统 · 平台资质与实操指引

> 当前阶段：**只做淘宝，TikTok 暂缓**。淘宝步骤见 [`淘宝开通指引.md`](./淘宝开通指引.md)。

面向公司自用铺货（有营业执照、本人/本公司店铺）。两条线并行：

- **读货**：浏览器扩展读 1688 商品页（1688 下载 API 普通开发者拿不到）
- **上架**：淘宝/TikTok 走**自用型官方 API**，自定义平台走通用适配器

资质这几件事必须由你本人在各平台后台操作，代码侧已就绪，拿到 Key 填配置即可联调。

---

## 一、总览：各环节由谁负责

| 环节 | 负责方 | 说明 |
| --- | --- | --- |
| 1688 商品读取 | 浏览器扩展 | 扩展读当前打开的页面，无需 1688 授权 |
| AI 加工 / 类目映射 | 铜龙助手前端 | 采集后必过此步，未映射商品被校验拦下 |
| 淘宝授权 + 发布 | 淘宝开放平台 API | 需企业开发者 + 自用型应用 + 商品发布权限 |
| TikTok 授权 + 发布 | TikTok Shop Partner API | 需公司资质 + 店铺授权 |
| 自定义平台 | 通用适配器 | 继承 `PlatformAdapter` 注册即可 |
| 部署与队列 | 铺货后端 | systemd 常驻，`DRY_RUN=1` 先试运行 |

## 二、淘宝开放平台（open.taobao.com）

### 2.1 准入

1. 用**企业支付宝**注册淘宝开放平台账号
2. 提交**企业开发者认证**（营业执照 + 对公账户；个人主体无法申请商品发布类权限）
3. 进入**控制台 → 应用管理 → 创建应用**，选择**「自用型应用」**
   - 自用型：只服务自己店铺，无需上架审核，通常**免费**
   - 记录 **App Key** 与 **App Secret**（Secret 只显示一次，妥善保存）

### 2.2 权限与授权

1. 在应用详情申请权限包：**商品管理 / 商品发布（taobao.item.add 等）**
2. 设置 **OAuth 回调地址**（授权后跳转），例如 `https://你的域名/dropship/auth/taobao/callback`
3. 生成授权链接打开、用**卖家账号**登录授权，拿到 `code`，后端回调换 `access_token`
   - 本系统：前端“去授权”按钮 → 后端 `/api/auth/taobao/authorize` → 平台授权页 → 回调

### 2.3 后端需要的配置

```bash
DROPSHIP_TAOBAO_APP_KEY=你的AppKey
DROPSHIP_TAOBAO_APP_SECRET=你的AppSecret
```

令牌临期时后端会**自动刷新**（`AuthCenter.ensure_valid`），无需手工换 token。

### 2.4 发布字段要点（最常踩的坑）

- **类目**：必须映射到叶子类目 `cid`，通过 `taobao.itemcats.get` 逐级取
- **必填属性**：不同类目必填属性不同，用 `taobao.itemprops.get` 拉取
- **主图**：先传到**图片空间**（`taobao.picture.upload`）拿 URL，再写入商品
- **标题**：含违规词/品牌词会被拦；先小批量试发
- **SKU 价格/库存**：`num_iid` 与 sku 数量要对得上
- **发布频率**：平台有配额限制，后端默认 30 次/分钟限频，可按权限调整

### 2.5 沙箱与试运行

- 开放平台提供**沙箱环境**，可先用沙箱 App 联调
- 本系统默认 `DROPSHIP_DRY_RUN=1`，不真正调用平台 API；确认无误后改 `0`

## 三、TikTok Shop（partner.tiktokshop.com）

### 3.1 准入

1. 用**公司主体**注册 TikTok Shop Partner Center
2. 创建应用（选择适合自用的应用类型），提交公司资质审核
3. 获取 **App Key / App Secret**，配置回调地址

### 3.2 店铺授权与发布

1. 授权链接让目标店铺授予 `product` 等权限，换 `access_token`
2. 取类目与属性（category / attribute 接口）
3. 调 product 创建接口上架；注意**物流模板 / 仓库**需先在后台配好

### 3.3 后端配置

```bash
DROPSHIP_TIKTOK_APP_KEY=你的AppKey
DROPSHIP_TIKTOK_APP_SECRET=你的AppSecret
```

> TikTok 适配器骨架已就位；拿到授权后按其 product API 补全字段映射即可。

## 四、自定义平台

1. 在 `dropship/server/adapters/` 新增 `xxx.py`，继承 `PlatformAdapter`
2. 实现 `map_fields(product, mapping)` 与 `publish(product, mapping, creds)`
3. 在 `adapters/__init__.py` 的 `build_adapters` 注册
4. 队列、前端平台下拉、授权中心都会自动带上它

## 五、部署与联调

### 5.1 后端上线

```bash
# 在服务器仓库根目录
bash dropship/deploy/install.sh
```

- 安装 `dropship.service`，监听 `127.0.0.1:9150`
- 环境变量写入 `/etc/xlx-dropship.env`，首次执行后请填写令牌与凭据，再重跑脚本

### 5.2 扩展与后端连通

后端只监听回环地址，扩展运行在**你的浏览器**里：

- 后端与浏览器同机：扩展填 `http://127.0.0.1:9150`
- 后端在远程服务器：通过 SSH 端口转发把服务器 9150 映射到本机，扩展仍填 `http://127.0.0.1:9150`
- 若设置了 `DROPSHIP_EXT_TOKEN`，扩展里填同样的令牌

### 5.3 端到端实操清单

1. 后端启动，前端铺货板块「测试连接」显示适配器列表
2. 浏览器装扩展，填地址与令牌，测试连接
3. 打开 1688 商品页 → 采集（预览面板勾选字段/图片）→ 货源库出现该商品
4. 前端完成类目映射、标题与售价，点「归档图」把图片落到本地
5. 选平台点「铺货」→ 任务队列消费 → 状态变「已上架」（`DRY_RUN=1` 时为「试运行」）
6. 失败任务点「重试」；`DRY_RUN=0` 后再跑一次完成真实上架

## 六、合规与注意

- 本系统**仅本公司自用**，不做对外 SaaS；请勿共享账号令牌
- 平台均有限频与内容规范，遵守配额，避免违规词与侵权图片
- 采集与发布的数据仅用于自家选品铺货，注意图片版权来源
