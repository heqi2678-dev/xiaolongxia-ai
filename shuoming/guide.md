# 小龙虾店说明书

进店地址：http://47.108.14.206/dian/

这是铜龙电商小龙虾的店门。展柜旧链已关闭，只走这一扇门。

## 怎么进

- 已有账号：输入账号和口令登录
- 新朋友：点「去注册」，填邀请码、账号、口令、再输一遍
- 邀请码只由主人发给熟人；换新后旧码立刻作废

## 闲聊和指挥店员

- 开关关着：闲聊。用你自己在「设置」里填的钥匙，写短剧、出网页
- 开关开着：指挥店员 Hermes 动手。可换大脑（DeepSeek / 千问 / 豆包 / 自定义）
- 朋友干活只落在自己房间，改不了店面
- 主人可指挥改店；说「可以发布」才推 GitHub

## 问用法

问某个库或工具怎么用时，先查官方说明再回答。钥匙各人付各人的。
